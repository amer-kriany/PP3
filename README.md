# Production Management System

A Java-based desktop application for managing production lines, tasks, and products.
This system allows supervisors to monitor production progress, manage tasks, and generate reports
through a user-friendly graphical interface built with Java Swing.

---

## 📌 Project Overview

The Production Management System simulates a real-world production environment.
Users can:
- Create and manage production tasks
- Assign tasks to production lines
- Track task status and progress
- Filter and search tasks efficiently
- View production history and generate reports

This project was developed as a **group university project** and presented during an academic discussion.

---

## ⚙️ Features

- Add, delete, and manage tasks
- Assign tasks to specific production lines
- Task status lifecycle (Pending, In Progress, Completed, Canceled)
- Product categorization and filtering
- Production line history by product
- Reports and statistics generation
- Interactive GUI built with Java Swing

---

## 🛠 Technologies Used

- Java
- Java Swing (GUI)
- Object-Oriented Programming (OOP)
- Git & GitHub

---

## 🧱 Project Structure

- `Task` – Represents a production task
- `Product` – Represents a product
- `ProductLine` – Represents a production line
- `ProductionManager` – Manages production lines and tasks
- `ProductionManagerGUI` – Main graphical user interface
- Additional dialogs and helper classes for task creation, filtering, and reports
